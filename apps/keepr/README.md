# Keepr

Colección privada de publicaciones, descripciones, enlaces y fotos para Android.

- [Descargar Keepr estable](https://github.com/deborahfam/app-releases/releases/tag/keepr-stable).
- ID de app: `keepr`. Canal exclusivo: `keepr-stable`.
- API pública: `https://api.github.com/repos/deborahfam/app-releases/releases/tags/keepr-stable`.
- Paquete Android: `com.keepr.app`.
- APK: `Keepr-<version>.apk`, acompañado de su archivo `.sha256`.
- Cada versión tiene un código de compilación creciente y una etiqueta histórica `keepr-v<version>`.
- El actualizador comprueba el canal y el ID de app; descarga desde la etiqueta histórica correspondiente para evitar que un cambio del canal sustituya un archivo durante la descarga.
- [Creador](https://github.com/deborahfam).

## Migración al canal público

Las versiones hasta 0.8.20 consultan el antiguo repositorio del código, ahora privado. Descarga la versión nueva desde el enlace anterior e instálala sobre la existente, **sin desinstalar**, para conservar tus publicaciones.

Desde la nueva versión puedes buscar, descargar e iniciar la instalación desde Ajustes de Keepr. Android pedirá confirmar la instalación y, si corresponde, permitir instalar actualizaciones desde Keepr.

El código y las claves de firma permanecen en el repositorio privado. Este canal contiene únicamente instaladores firmados y checksums.
